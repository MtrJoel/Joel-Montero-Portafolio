Quorom Académico

Spring BootReact PostgreSQLDockerFull Stack

Plataforma full-stack desarrollada de cero para resolver un problema real identificado en mi propia universidad: la falta de un canal organizado para que los estudiantes consoliden solicitudes de asignaturas y horarios ante la dirección de carrera. Presentada formalmente como propuesta institucional.

  • Full stack real: backend Spring Boot + API REST, frontend React, PostgreSQL — diseño, implementación y despliegue individuales.
  • Demanda colectiva: estudiantes se suman a solicitudes existentes en vez de duplicarlas.
  • Producción: Docker en Render + Vercel, CORS y variables de entorno configuradas.
